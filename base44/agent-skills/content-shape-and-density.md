# Skill: content_shape_and_density

Controls **form and density of content only**. It never changes, chooses or questions the template, the layout, the column structure or any design setting.

## Procedure

1. **Determine the section's real placement** from the layout information in the supplied context: is this section rendered in a narrow/compact area, or in the wide main area?
2. **If placement cannot be determined reliably, prefer concise wording.** Never invent a layout interpretation, and never assume a design that is not stated.
3. **Choose the form that fits the slot:**
   - **Narrow / compact section** — keywords, a short phrase, or a single tight line. A few words are usually sufficient and usually better.
   - **Wide / main section** — a fuller description is acceptable when it genuinely adds value: a concrete result, a scope, a differentiating detail.
4. **Apply the restraint test** to every proposed text: does each added clause add value the reader needs? Remove what only adds length.
5. **Balance three factors explicitly** — content value, readability, and available space. Length is never justified merely by the existence of more information.
6. **Constrain other recommendations.** Any proposed wording produced elsewhere in the review must respect the density verdict for its target section.

## Boundaries

- Never propose moving a section, changing columns, switching template, or altering layout to make text fit. If text does not fit, shorten the text.
- Density is a property of the *proposal*, never a reason to invent or delete substantive facts.
- Section identity and target fields come from the CV index; this skill does not redefine them.
