# Course Discovery

## Purpose
اكتشاف دورات إضافية حقيقية تساعد المستخدم على تطوير مساره المهني بناءً على آخر CV معتمد.

## Trigger
يُشغّل البحث بعد حفظ CV صراحةً أو بعد عملية Print/PDF فعلية للنسخة الحالية. لا يرسل إشعارًا لمجرد حدوث trigger.

## Method
- استخدم آخر نسخة CV محفوظة.
- استخرج المهنة/المسار والمهارات الحالية والمهارات التي يمكن تطويرها.
- ابحث في السوق عن دورات حقيقية وملائمة، وفضّل المصادر المحلية/الموثوقة عند توفرها.
- قارن النتائج بما سبق حفظه للمستخدم.
- لا تعدّ الدورة جديدة إذا كانت موجودة مسبقًا وفق courseKey.

## Notification rule
- لا توجد دورات إضافية جديدة → لا Notification ولا Email.
- توجد دورات إضافية جديدة → احفظ الدورات الجديدة فقط، ثم أرسل إشعارًا واحدًا يذكر عدد الدورات الإضافية ويقود إلى Recommended Courses.
- لا تعيد إشعار المستخدم بالدورات التي سبق حفظها.
